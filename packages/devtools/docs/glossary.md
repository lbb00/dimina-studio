# 术语表

这里只收录读代码和维护文档时绕不开的名称。日常能用中文说清的词不会单独列出。

## 运行位置

### 主进程

Electron 中创建窗口、管理项目和处理消息的进程。它负责实际的窗口和文件访问，不要和显示按钮和面板的界面页混淆。代码中通常称为 `main process`。

### 界面页（`renderer`）

用户看到的 React 界面，例如项目列表和布局面板。它提交用户操作和位置，不能直接管理原生网页视图。

### Electron 原生网页视图（`WebContentsView`）

由主进程放进窗口的网页区域，用来显示模拟器、编辑器或调试工具。它不是普通 DOM 元素，位置只能由主进程统一管理。

### 预加载脚本（`preload`）

网页加载前执行的脚本，用来暴露少量允许调用的接口。它不是页面业务代码，也不应暴露任意 Node.js 能力。

## 小程序运行

### 一次项目运行（`session`）

用户打开一个项目后产生的一整套编译、页面和状态。切换或关闭项目后，旧的一次运行返回的结果不能再更新界面。

### 逻辑层窗口（`service-host`）

隐藏的网页窗口，运行小程序逻辑代码。它不画页面，页面内容在 `render-host` 中显示。

### 小程序页面（`render-host` `<webview>`）

设备框里实际显示小程序页面的网页。它不等同于最外层模拟器视图，也不负责绘制 TabBar。

### 消息转发（`Native Bridge`）

逻辑层、页面和主进程之间传递页面数据、事件和小程序 API 请求的通信方式。它不是让页面直接调用 Electron API 的通道。

### 独立存储区（`partition`）

Electron 为网页划分的网站数据范围，其中包括 Cookie、缓存和本地存储。预热窗口默认可以继续使用这些数据，因此归还窗口不等于清空存储。

### 预热窗口集合（`pool`）

提前创建的逻辑层窗口集合，用来缩短打开项目的等待。没有可用窗口时仍会新建窗口，不会阻止项目打开。

## 调试与编辑

### 被调试的页面（CDP `target`）

Chrome DevTools Protocol 当前连接的网页，例如页面、逻辑层或主窗口。页面切换后旧节点和执行环境会失效。

### 当前全部位置和显示状态（`placement snapshot`）

界面页一次上报的所有原生网页视图位置、尺寸和是否显示。主进程只按最新这一份放置视图，避免旧界面把已关闭的视图重新显示。

### 递增编号（`generation`）

用于区分先后请求的数字。异步结果回来时，编号不是当前值就说明它属于旧操作，应被忽略。

### 为编辑器提供文件的本机网页服务（`COI server`）

给内嵌编辑器提供页面文件和项目文件的本机服务。它还会设置浏览器要求的响应头，让编辑器可以启动需要共享内存的后台任务。保存文件仍要经过主进程。

### 项目数据来源（`provider`）

告诉 DevTools 项目列表和模板从哪里读取的对象。它不负责打开项目后的编译工作。

### 处理函数（`handler`）

收到一个注册名称对应的请求后执行的函数，例如自定义小程序 API。它应校验输入并只处理自己负责的动作。
