# 小程序文件系统

小程序文件 API 使用虚拟路径，不能直接访问电脑上的任意路径。运行程序会把临时文件、用户数据和项目资源放到当前小程序可以访问的位置。

## 当前行为

- `difile://` 指向当前项目运行期间管理的临时文件，适合把用户选择的图片或视频交给小程序。
- 用户数据目录由运行程序管理。小程序可以读写这些数据，并在下次启动时继续读取。
- 项目资源通过运行程序提供的网址读取，小程序看不到电脑上的绝对路径。

选择图片或其他本机文件时，主进程先把文件复制到当前项目可以访问的位置，再把虚拟路径返回给小程序。小程序不能依赖文件原来的电脑路径。

## 限制与错误

网址格式错误、使用其他项目的路径、文件不存在或目录操作不受支持时，请求会失败。调用代码应处理失败结果，不要把虚拟路径传给 Node.js `fs`。临时文件只保证在当前项目打开期间可用。

## 维护入口

- `packages/dimina-electron-runtime/src/shared/vpath.ts`：虚拟路径解析。
- `packages/dimina-electron-runtime/src/main/services/simulator-temp-files/`：临时文件存储与请求处理。
- `src/simulator/simulator-api-fs.ts`：模拟器文件 API。

文件系统请求由主进程转发，见[小程序逻辑层和页面如何通信](./native-bridge-protocol.md)。
